# 液态玻璃设计系统参考（按需加载）

本文件为 `studydesk-ui-system` 的深层参考：完整视觉语言、组件清单与页面级规范。
仅在需要更细粒度设计决策时加载。

## 1. 视觉语言

- **风格关键词**：液态玻璃、毛玻璃、轻盈、通透、沧浪青点缀
- **表面层级**：背景（页面底色）→ 玻璃卡片（主容器）→ 强调面（accent-soft 填充的交互区）
- **光效**：顶部 1px 内高光 + 柔和投影；卡片 hover 时透明度提升、阴影加深
- **圆角体系**：卡片 16px、面板 12px、按钮 8px、输入框 8px

## 2. 页面级规范（与现有实现对齐）

| 页面 | 布局要点 |
|---|---|
| 今日 `/today` | 问候横幅 + 今日课表 + DDL + 习惯/专注/随手记分区 |
| 课表 `/schedule` | 周次横幅 sticky 顶部；左节次时间轴 + 星期栏（月份/日/周几）+ 课程彩色块 |
| 任务 `/tasks` | Tabs 状态分组 + 拖拽看板 |
| 笔记 `/notes` | 列表 + Milkdown 编辑器（Nord 主题） |
| 刷题 `/quiz` | 题库列表 / 详情 / 练习 / 导入向导 |
| 习惯 `/habits` | 习惯卡片 + 打卡勾选 |
| 专注 `/focus` | 计时环 + 关联任务 |
| 记账 `/finance` | 月度日历 + Recharts 图表 |
| 启动台 `/launcher` | 分组网格 |
| AI `/chat` | 输入框固定底部 + 流式消息 |
| 文档 `/docs` | 文件卡片 + 悬停环形菜单 |
| 设置 `/settings` | 分组设置项 |

## 3. 字号基线

| 层级 | 值 | 用途 |
|---|---|---|
| xs | 12px | 标签、辅助说明 |
| sm | 14px | 次要信息 |
| base | 16px | 正文（默认） |
| lg | 18px | 卡片标题 |
| xl | 22px | 页面标题 |

## 4. 主题切换

- 主题由 `lib/theme.ts` 管理（class 切换），`.dark` 类挂在根元素
- 所有自定义 token 必须成对提供 `:root` 与 `.dark`
- Tailwind 语义色（`bg-muted`、`text-muted-foreground` 等）来自 shadcn 主题变量，与自研 token 共存
