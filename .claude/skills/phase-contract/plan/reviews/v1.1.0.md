## 4. 发现的问题

1. **[严重·已修复]** Electron 打包白屏：`dist/output/index.html` 引用 `./assets/*`，但 assets 只写入 `dist/output_resource`，而 electron-builder 只打包 `dist/output` → 现在无 CDN 前缀时同时写入 `dist/output/assets`，引用 6/6 存在。
2. **[严重·已修复]** PWA 预缓存为空：VitePWA 的 `closeBundle` 默认最后执行，资源已被 miaoda 插件清理 → 设置 `integration.closeBundleOrder: 'pre'`，恢复 80 条预缓存。
3. **[一般·已修复]** pdfjs-dist 6.4 API 漂移导致 typecheck 失败；test report 的「0 error」已过期。
4. **[提示·遗留]** ChatPage / DocsPage 仍有 `bg-gray-*` / `bg-blue-*` 等非语义色，违反 UI Skill §3，建议单开 UI phase 迁移。
5. **[提示·遗留]** `echarts`、`echarts-for-react`、`framer-motion`、`@gsap/react`、`gsap` 无源码引用；按架构闸门需单独确认后移除。
6. **[提示·遗留]** NoteEditorPage chunk 763.66 kB（Milkdown），可后续评估拆分或按需加载。
