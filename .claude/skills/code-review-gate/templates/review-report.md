# Code Review Gate 审查输出模板

```markdown
## 审查结果
- Phase/变更：
- 静态检查：typecheck ✅ / ❌ · lint ✅ / ❌ · build ✅ / ❌
- 行为验证：
  - 通过项：...
  - 未覆盖项（说明原因）：...
- 范围审计：✅ 无越界 / ❌ 越界项清单
- 发现的问题：
  1. [严重/一般/提示] 描述 → 修复建议
- 结论：✅ 通过 / ❌ 需修复后重审
```

## 手动冒烟清单（按改动范围勾选）

- [ ] 新建一条记账 → 刷新页面 → 记录仍在
- [ ] AI 说"今天午饭 25" → 产生一条餐饮支出
- [ ] 课表切周次 → 课程按周次模式正确过滤
- [ ] 删除操作 → 确认弹窗出现 → 软删除生效
- [ ] 深浅主题切换 → 无死色/突兀色块
- [ ] PDF 转图片 → 正常导出（20 页上限）
